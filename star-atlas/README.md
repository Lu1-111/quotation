# Star Atlas · 语录星图（完整测试版 V1）

以原版 **3D 知识星图**（`galaxy.js`）为交互核心、以独立 **数据工作台**（`/workbench`）为登录与管线入口的多智能体个人知识体系构建系统。零外部配置即可开箱运行：支持工作台页面内知乎扫码登录、可选知乎官方 OAuth 浏览器授权、高速知乎数据采集、同步画像更新、噪音过滤与知识点提炼，以及实时监听星球数据库写入 3D 星图。

## 一、快速启动

### 方式 A：Docker 一键启动（推荐，零本机环境依赖）

镜像内置 Node.js 24、Playwright Chromium 与中文字体，拉取代码后无需安装本机浏览器或手动配置环境变量即可直接运行：

```bash
cd star-atlas
docker compose up --build -d
```

启动后访问：
- **数据工作台（第一步：登录、同步、查看画像与星球库）**：http://127.0.0.1:3300/workbench
- **星图首页（原版液态星球封面 + 黑洞坍缩进入 3D 星图）**：http://127.0.0.1:3300/
- **健康检查**：http://127.0.0.1:3300/health

如需使用真实大模型（如 DeepSeek、OpenAI 兼容端点），无需重启容器，直接在工作台 **「大模型设置」** 面板填写 Base URL、Model Name 与 API Key 即可生效（密钥持久化在容器 `/app/.data` 数据卷中）；也可通过环境变量或 `.env` 传入。

### 方式 B：本机 Node.js 24+ 直接运行

```bash
cd star-atlas
npm ci
npm start
```

Windows 用户也可直接双击 `start.cmd` 自动启动并打开工作台页面。

## 二、全流程体验步骤（从登录到生成星图）

1. 打开 **http://127.0.0.1:3300/workbench**（数据工作台）。
2. **完成知乎登录**（两种页面内登录方式任选其一）：
   - **工作台内扫码登录（推荐，零配置直接可用）**：点击「在页面内加载知乎二维码」，使用手机知乎 App 扫码并在手机确认，工作台自动检测到知乎昵称后切为已登录状态；
   - **知乎官方 OAuth 授权登录（可选）**：在 `.env` 填入 `ZHIHU_OAUTH_APP_ID` 与 `ZHIHU_OAUTH_APP_KEY` 后，点击「在浏览器打开知乎官方授权」即可前往知乎官方授权页并自动回调回工作台。
3. **点击「同步浏览历史并生成星图」**（或点击「演示数据一键体验」在无账号时立即体验全链路）：
   - 数据采集模块高速同步近 50 条浏览记录（受控并发 + 7 天详情缓存 + 增量边界扫描，目标初次 ≤ 15 秒 / 增量 ≤ 10 秒）写入带前置 `$formatDeclaration` 的 `data/user-db.json`；
   - **画像 Agent** 与采集同步绑定运行，更新 `data/profile.json`；
   - **数据转换 Agent** 过滤网文、日常、娱乐八卦等非知识噪音，提炼结构化知识点写入带前置 `$formatDeclaration` 的 `data/planets-db.json`；
   - **星图写入 Agent** 实时监听 `data/planets-db.json` 变动（进程内事件 + `fs.watch`），按语义归并知识领域（如将 `AI` 与 `人工智能` 归为同一星系）、划分分支色系并建立同分支/跨分支连线，写入 `data/star-map.json` 并通过 SSE 实时推送前端。
4. 点击右上角 **「直接看 3D 星图 →」** 或返回 **「星图首页」** 点击封面液态星球进入 3D 知识星图。

## 三、架构与数据规范

- **用户数据库**（`data/user-db.json`）：顶部包含 `$formatDeclaration` 格式声明，沿用原采集框架 v3 快照结构。
- **星球数据库**（`data/planets-db.json`）：顶部包含 `$formatDeclaration` 格式声明，采用分条记录（自增编号 `PL-0001`、所属领域 `domain`、知识点 `knowledgePoint`、内容摘要 `summary`、权重 `weight`、落图状态 `status`）。
- **测试命令**：`npm test`（覆盖数据库格式声明、50 条并发采集耗时基准、噪音过滤、语义领域归并、分支配色、跨分支连线与完整 HTTP 端到端闭环）。
