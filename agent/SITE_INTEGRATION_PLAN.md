## P0-A 新版云授权撤回与外发预览

**已复现。** 一个已同意云推理的会话提交 `cloudConsent: false`，当轮返回 403，读取会话却仍显示 `true`。下一轮省略该字段仍可调用模拟云模型，重启后也一样。另用 240 字合成片段验证，预览只显示前 160 字，后段标记仍进入模型请求。[同意处理](server.mjs#L917) · [预览裁剪](turn-orchestrator.mjs#L2379) · [提示词组装](turn-prompts.mjs#L227)

**实施。** 现有轮次接口在完成身份和会话所有权校验后，对显式 `false` 先持久化撤回，再返回本轮是否允许执行。会话里的旧授权和兼容字段都以最新状态重算。重复撤回幂等，图版本保持原值。后续省略该字段时读取已保存的值。发起云模型调用前核对最新授权，撤回时向正在运行的相关轮次传递取消信号。

从本机已授权快照选取并裁剪片段，生成一份拟外发清单。预览与模型请求共用这些片段的实际文本、来源和范围。云端个人材料先预览、再确认发送。沿用 `CLOUD_CONSENT_REQUIRED` 响应承载新预览，以 `outboundPreviewId` 绑定确认。只有与已确认清单匹配的个人片段才能进入本轮云请求。需要不同片段时返回新预览。回环模型继续按本机材料授权运行。同步更新 HTTP 契约、Schema 和合成样例。

**HTTP 验收 R-A1。** 使用临时 SQLite 和捕获模型输入的替身。① 同意后提交一轮成功。② 同会话撤回，云模型调用数不增加，`GET /v1/sessions/:id` 返回 `cloudConsent: false`。③ 下一轮省略该字段，返回 403，模型调用数保持原值。④ 重启服务再次提交，结果一致。⑤ 重新确认当前预览后恢复调用。另验回环模型在云同意为 false 时仍可使用已授权的本机材料。

**HTTP 验收 R-A2。** 用前 160 字和后段均有可辨认标记的合成片段核对模型实际请求。预览与请求中的个人片段逐项匹配，包括证据 ID、来源、裁剪范围和实际文本。改变涉及的片段后，旧确认不能放行。覆盖一轮在发起模型调用前撤回，确保调用仍为零。

## P0-B 旧工作台画像授权

**已复现。** 配置非回环模型，`allowPersonalData: false` 时，启动自动画像和 `POST /api/profile/refresh` 仍会把合成个人记录交给模拟生成器。同步成功与保存设置也会触发同一入口。[同步入口](web.mjs#L328) · [画像生成](web.mjs#L372) · [设置入口](web.mjs#L575) · [启动入口](web.mjs#L992)

**实施。** 手动刷新与所有自动触发共用一个画像门禁。在读取素材和构造模型输入前检查个人材料许可。旧工作台本轮只开放已授权的回环模型画像。非回环画像在具备与新版一致的显式同意和材料预览之前，返回明确的未授权状态。设置关闭后停止后续自动画像，向运行中的生成任务传递取消信号。采集与只读快照继续作为独立能力使用。

**HTTP 验收 R-B1。** 用真实工作台 HTTP 入口、合成采集替身和可计数生成器覆盖启动、同步完成、保存设置、手动刷新。关闭个人材料时，模型生成调用均为零，新画像不落库。开启个人材料但使用非回环模型时，旧画像仍拒绝调用。开启个人材料且回环模型可用时，手动生成成功。测试运行中关闭设置和关闭后重启。

## P1-C 正式星图接入新版接口

### 单一入口与页面状态

提供 `cd agent && npm run serve:demo:web`。本机回环入口服务 `frontend-design/web/` 的正式首页，并通过同源方式调用新版 `/v1`。宿主管理内部 Bearer，页面通过同源会话访问允许的接口。现有 Bearer API 保持兼容。合成入口使用独立数据库与合成上游，浏览器资源、存储及事件流只交付页面所需数据。

沿用现有星图与承重分析布局，添加句子输入、当前轮次和可操作的证据卡。创建合成会话时明确展示模式。普通输入提交到 `POST /v1/sessions/:id/turns`。焦点、改写采纳和撤回使用后端返回的实际 ID。浏览器从 API 取材料与报价，已有固定案例继续用于原验收脚本。

### 事件与交互

| 交互 | 客户端行为 |
| --- | --- |
| 分析句子 | 用新的 `clientRequestId` 和当前图版本提交，通过返回的 `eventsUrl` 订阅 SSE。显示 `focus.selected`、实际阶段和增量解释 |
| 查依据和纠错 | 从 `evidence.verified` 与会话证据索引显示来源。节点点击绑定 `focusRef.nodeId`。用后端事实 ID 确认或撤回 |
| 更新星图与账单 | 收到 `turn.committed` 后用对应 `graphVersion` 更新。图和账单始终同版。可用图差异更新或重新读取快照 |
| 比较和采用 | 原句与改写按服务端 `statementComparison` 并列。空比例显示“暂未确定”。采用结果遵循实际的 `adoptStatementId` |
| 取消和恢复 | 停止按钮调用取消接口。按 `Last-Event-ID` 补齐断线事件并去重。刷新后以 `GET /v1/sessions/:id` 恢复同一会话。遇到版本过期时刷新状态并让用户决定重试 |

报价数字、冲突项和引文从结构化结果渲染，增量解释单独显示。待确认、已提交、失败和取消各有可见状态。没有图或证据时提供可继续操作的空态。[HTTP/SSE 契约](HTTP_API_CONTRACT.md)

### 浏览器验收 R-C1 与 R-C2

**R-C1 正常路径。** 从正式首页进入合成会话，输入“推荐算法只会让人的兴趣越来越窄”。看到系统选出焦点并打开一条有来源的合成证据。授权者角色补充“我确实通过推荐发现过新乐队”，看见一次可核对的已提交图变化。再补充一条独立事实，随后提交换语气和缩小范围两份改写。比较使用同一图版本，能明确采用其中一份。撤回最早的指定事实，验证对应节点和报价更新，独立事实仍在。再换一句来自其他领域的输入，验证页面可以提交并展示真实响应。

**R-C2 恢复与异常。** 在桌面、手机尺寸分别覆盖加载、空图、证据不足和请求失败。用可控模型暂停输出，在第一段已显示时中断订阅，按事件 ID 恢复。另跑一次主动取消和浏览器刷新。自动化应断言实际出现创建、提交、SSE 和快照请求，页面上的原句、节点 ID、引用和报价来自响应。整个流程在没有外部凭证的环境可复跑。
