# CLI 模块约定

- 用户已明确要求独立 CLI 版本，本目录为 `data-collection-cli/`，不修改其他模块或根目录共享文件。
- 文件名用英文，说明和新测试描述用中文；提交使用当前仓库本人署名。
- 本目录必须能独立复制和运行，不通过相对路径依赖其他模块的源码、依赖或数据。
- 真实采集需要本人登录和采集同意，演示使用独立合成数据；不向模型输出 Cookie 或授权凭证。
- 每个档案数据库与浏览器状态独立，命令运行许可不能改变网页版的页面在线限制。
- 不混入未发布的 OAuth 补充代码，不修改原前端设计。
- 发布前运行本模块 `npm test`、Schema 校验，并检查只暂存本目录。不要提交 `.data/`、`.env`、登录状态或真实导出。
